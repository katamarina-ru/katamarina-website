Katamarina является доверенной PaaS-платформой для построения гибридных инфраструктур.

Katamarina позволяет легко трансформировать ваш парк серверов в интеллектуальную систему с помощью простого REST API для развертывания Kubernetes кластеров, виртуализации и контейнеризации, сервисов баз данных (DBaaS), виртуальных машин, балансировщиков нагрузки, HTTP-кэширования и других сервисов.

Используйте Katamarina для одновременого управления контейнерами и виртуальными машинами для создания собственной инфраструктуры как для продуктивной нагрузки, так и для предоставления недорогих сред разработки.
